# Docs index

Generated by `pnpm doc index` from the files below and the doc citations in code comments; a test fails when it is stale. Do not edit it by hand.

Read a section, not a file: `pnpm doc section <file> "<heading>"` prints one section with its subsections (the file may be a basename such as `brief`). The line range works with an offset and limit too. ~tok is bytes / 4. `← n` is how many code files and docs cite the section; the last part of this file lists the code citations by area.
