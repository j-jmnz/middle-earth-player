# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in all project spaces and for anyone representing the project elsewhere.

Criticise the work, not the person. No harassment, insults, sexualized language or personal attacks.

## Reporting

Report privately to the maintainer, through the Security tab ("Report a vulnerability" opens a private thread) or a direct message on GitHub. Reports are confidential. The maintainer may remove, edit or reject contributions that break this code, and may ban a contributor temporarily or permanently, following the Contributor Covenant's enforcement guidelines.
