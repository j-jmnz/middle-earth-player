# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the issues, pull requests, discussions and every other project space, and to anyone representing the project elsewhere.

In short: be welcoming and patient, assume good faith, give and take criticism of the work rather than the person, and leave out harassment, insults, sexualized language and personal attacks.

## Reporting

Report unacceptable behavior to the maintainer privately, through the repository's Security tab ("Report a vulnerability", which opens a private thread) or by a direct message to the maintainer on GitHub. Reports are kept confidential. The maintainer may remove, edit or reject comments, commits, code and issues that break this code, and may ban a contributor temporarily or for good, following the Contributor Covenant's enforcement guidelines.
