# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in every project space, and to anyone representing the project elsewhere.

Criticise the work, not the person. Harassment, insults, sexualized language and personal attacks are not tolerated.

## Reporting

Report a problem privately to the maintainer, either through the Security tab, where "Report a vulnerability" opens a private thread, or by direct message on GitHub. Reports are kept confidential. Following the Contributor Covenant's enforcement guidelines, the maintainer may remove, edit or reject contributions that break this code, and may ban a contributor temporarily or permanently.
